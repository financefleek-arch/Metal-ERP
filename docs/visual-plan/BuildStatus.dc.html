Metal ERP — build status against the plan

Milestone 1 = the shop can register, set up the firm, load parties & items, raise an invoice, and download a print-accurate A4 PDF (no GST columns). Live at metal.fleekfinance.in with push-to-deploy. Inventory / stock is not M1 — it’s Stage 3.
