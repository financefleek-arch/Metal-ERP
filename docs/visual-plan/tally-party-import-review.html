Nothing is written until you press Import.

Matching & write rules

Per ledger, in order:
  • GSTIN exact against party.gstin (any role) → link + fill blanks: set tally_guid, and copy phone / email / PAN / address / PIN only into fields that are currently empty. Never overwrites a non-blank value. If the matched party's role differs, widen to both (never narrow).
  • No GSTIN on the ledger → PAN exact against party.pan → same link + fill-blanks.
  • No PAN match → normalized-name trigram ≥ 0.82 to a single party → flag for review: the row offers link to it / create new. Never auto-links on a name alone.
  • No match → create new: source = tally_import, source_ref = <Tally GUID>, role from the group lineage, one party_address (type both) from the ledger's <ADDRESS.LIST> + PINCODE, state from LEDSTATENAME (mapped to a code) or the GSTIN prefix.
Auto-flagged (excluded from Import until fixed): a name-only near-match; a legal name > 140 chars or with disallowed characters; a GSTIN/PAN that fails validation; a ledger under both Debtors and Creditors lineages; a duplicate GSTIN within the file itself.
