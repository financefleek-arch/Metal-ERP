Phase 2 — not built yet, shown for context

What flipping GST mode adds

On the invoice editor
  • GSTIN on business & party; Place of Supply selector
  • Per-line GST rate + “rate incl. tax” toggle
  • Auto CGST+SGST vs IGST from state comparison
  • HSN becomes required, pulled from item master
On the printed document
  • Title → “Tax Invoice”; IRN / Ack No. / Ack date header
  • Signed QR code block
  • CGST / SGST columns in the line table
  • HSN-wise tax summary table
  • Second page: full e-Way Bill
New machinery
  • GSP client (IRP auth, INV-01 payload, IRN, QR)
  • e-Way Bill generate + Part-B update
  • Job queue + status state machine per invoice
  • GSTR-1 export (B2B / HSN sheets)
Why it’s additive, not a rewrite
  • Schema already carries every GST column (nullable)
  • Money in paise, totals frozen at finalize from day one
  • Gap-free numbering keyed by financial year
  • PDF template versioned per invoice — old ones unaffected
  • Same tax-core function, new branches
  • HSN already a validated FK; confirmed items already carry it
Maturity ladder — each rung is a shippable release
0 · Bootstrap
Normalized free-typed lines (key + synonym map), auto-created items, bill lifecycle + roles, weighbridge agent, manual weight fallback, structured UOM/category enums
1 · Accreting
Fuzzy type-ahead + near-miss nudge, monthly reports, merge tool + dashboard widget, role queues, PWA for rate-approval
2 · Curated
Types set, HSN/UOM, dedup, variant groups, item codes assigned. GST slots in here.
2.5 · Barcode
SKU labels for MRP, 1 scanner, scan-mode billing, mfr-EAN capture
3 · Stock
Opt-in in/out per variant, scans move stock, low-stock flags
4 · Inventory
Lot labels at cutting, weighment-linked, purchase→itemise→sale, valuation
One deployment artifact outside the cloud app: the connector agent on the counter PC — serial-in from the scale, label-print out, Tally XML both ways (import masters at Stage 0, push vouchers at Stage 2). Later, an optional serial→WiFi converter for PC-less scales. Barcode scanners need no software.
