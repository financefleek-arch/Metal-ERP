What this changes behind the screen

  1. Simple bills ask for two things: shop name and phone. PAN, state and legal name are gone. No field is "required but unused".
  2. GST mode asks for the GSTIN and reads state and PAN from it, so nobody types the same fact twice. The bill title locks to "Tax Invoice".
  3. Today's Setup checklist counts "firm details" as done once address and state are filled. In simple mode it would be done after name and phone.
  4. Existing shops with a GSTIN on file start in GST mode, everyone else in Simple. New sign-ups start in Simple.
  5. Fixes included: UPI-only shops now print their UPI and QR, the account holder is printed, and Terms can be edited.
