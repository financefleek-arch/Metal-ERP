Import to Tally

Creates stock items in your Tally company. Not the whole catalog by default.

  • 1 · ChooseSelected rows, a filter, or all priced items.
  • 2 · CheckCompared with what is already in Tally: 2 name clashes units ready
  • GroupsEach of our groups is matched to a Tally stock group by name. Glassware: exists Beer Mugs: will be created Existing Tally groups are never moved or renamed.
  • 3 · PushSent in batches of 200 through the Tally agent. Re-push updates items, never duplicates them.
  • 4 · Result412 created 18 updated 3 failed with the reason per item.
Items we push become real items in Metal ERP too, so they can be billed and scanned.

Codes and barcodes

Item code is ours, generated at import

GL-000412
  • Format: shop prefix, a dash, a six-digit counter. Counter never repeats, even if an item is excluded.
  • Stays with the item when it moves into your item list and into Tally.
  • Supplier code is kept as a reference column. It is how a re-sent catalog finds the same item again.
  • Barcode: Code 128 of the item code. Works on any scanner and needs no registration.

Questions for you

  1. Multiplier or percent? You asked for a multiplier. The screen shows both (×1.25 = +25%). OK to type either?
  2. Code prefix. One prefix for the shop, or one per supplier or category (GL for glassware)?
  3. Barcode on what? A set of 6 sells as one pack. One barcode per pack, or one per single piece too?
  4. Tally group. What does your Tally group stock by: product type (Beer Mugs), department (Glassware) or brand (DELI)? We can read your existing groups from Tally to match.
  5. Label printer. Which size do you print on today? That fixes the default label template.
