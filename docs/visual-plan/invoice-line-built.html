Behaviour notes

  • Unit: always a dropdown, preselected to the item's uom (or rate_mode default for a new line). Options = the item's own unit(s) (uom + secondary_uom) then nos + kg, deduped — overridable per line, but not the raw 16-entry vocab. New typed item → piece/kg choice in the strip sets rate_mode + default uom. Rate label follows the selected unit.
  • Discount: one field + ₹/% toggle. % is resolved to ₹ in toLineIn and the totals preview; the backend line still stores an absolute amount (a "10 %" line reloads as "₹236").
  • Guards (lineProblems(), pure): qty/rate/unit missing (block), rate outside price_min/max (warn), discount % > 100 (block), discount ≥ line total (block), HSN not 4/6/8 digits (warn), free-text line (warn) + piece/kg prompt, "also on line N" when the same item repeats.
  • tax.py untouched — line total still qty × rate − disc.
  • Backend: secondary_uom + last_sold_at added to ItemListItem (feeds /items?q= and /items/resolve). No migration.
