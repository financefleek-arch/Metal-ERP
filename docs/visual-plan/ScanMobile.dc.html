Mobile surfaces stay small and task-shaped: scan stock in, approve a rate, check status, today’s sales. Full invoice creation on a phone is modelled but built last. PWA first (installable, camera works), native only if needed.
Every mobile write carries actor + device + timestamp server-side, with an idempotency key — a phone on a weak signal will retry, and must not double-add a line or re-attach a weighment.
